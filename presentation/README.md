# WHR 系统介绍演示材料

本目录用于线下验收。推荐打开 `WHR语言课程设计_v1.0.pptx` 进行讲解；PDF 是版式稳定的预览与备用文件。

## 文件

- `WHR语言课程设计_v1.0.pptx`：12 页可编辑演示文稿，表格和性能图表均为原生对象。
- `WHR语言课程设计_v1.0.pdf`：由最终 PPTX 导出的 12 页 PDF。
- `验收讲稿.md`：按页组织的“是什么—为什么—如何实现—如何证明”讲稿。
- `现场演示脚本.md`：五分钟内可完成的命令、预期结果与故障备用方案。
- `常见问答.md`：围绕语法、解释器、测试、性能和 Agent 应用的答辩问题。
- `build_presentation.mjs`：PPT 的生成源，便于后续调整内容。

## 建议节奏

PPT 讲解约 7 分钟，现场命令演示约 5 分钟，问答预留 3 到 5 分钟。正式验收前先执行：

```bash
python scripts/check_project.py
```

演示时只使用仓库中的正式结果，不临时重新跑性能测试，避免机器负载造成数据波动。
