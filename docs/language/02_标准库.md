# WHR v1.0 标准库

WHR v1.0 的内建函数保持最小化，只提供课程要求、测试和综合应用真正需要的能力。所有参数从左到右求值。

## 1. 输入输出

### `show(values...) -> null`

将任意数量的值写入标准输出：参数之间一个空格，末尾一个换行。无参数时输出空行。返回 `null`。

### `read() -> string | null`

### `read(prompt) -> string | null`

可接受 0 或 1 个参数。提示值必须是字符串，原样输出且不换行。随后读取标准输入一行并移除行尾；EOF 返回 `null`。

## 2. 长度和数组操作

### `len(value) -> integer`

参数必须是字符串或数组。字符串长度按 Unicode 码点计数，数组长度为元素个数。

### `push(array, value) -> integer`

把值追加到数组末尾，原地修改数组并返回新长度。

### `pop(array) -> any`

移除并返回数组最后一个元素。空数组产生运行时错误。

## 3. 显式转换

### `to_int(value) -> integer`

- 整数原样返回；
- 字符串必须匹配可选的一个前导 `-` 加一个或多个十进制数字；
- 不允许前后空白、前导 `+` 或其他格式；
- 其他类型或非法字符串产生运行时错误。

### `to_string(value) -> string`

返回该值的 WHR 文本表示。字符串本身原样返回；复合值遵循语言规范中的确定性表示。

### `type_of(value) -> string`

返回下列类型名之一：

```text
integer string boolean null array shape function shape_type
```

用户函数和内建函数都返回 `function`，不同结构类型的实例都返回 `shape`。

## 4. 设计说明

标准库有意不加入随机数、时间、文件访问或网络访问：

- 避免降低测试与演示的确定性；
- 避免把大作业重点从解释器核心转移到宿主 API 封装；
- 性能实验由外部基准驱动器计时，不依赖 WHR 内部时钟。
