# WHR v1.0 规范示例与预期行为

本文件在解释器实现前进行“纸面测试”：根据规范推导程序行为。阶段 2—4 会把这些场景转成可执行黑盒测试。

## 1. 完整导览程序

文件：[language_tour.whr](../../examples/language_tour.whr)

```text
student: WHR
scores: [92, 88, 96, 100]
average: 94
level: excellent
```

预期标准错误为空，退出码为 0。

## 2. 功能判定表

| 场景 | 程序片段 | 预期行为 |
|---|---|---|
| 整数优先级 | `show(2 + 3 * 4);` | 输出 `14` |
| 整数除法 | `show(-7 / 2, -7 % 2);` | 输出 `-4 1` |
| 字符串连接 | `show("W" + "HR");` | 输出 `WHR` |
| 禁止隐式转换 | `show("n=" + 1);` | RuntimeError，退出码 70 |
| 严格布尔 | `when 1 { show("x"); }` | RuntimeError，退出码 70 |
| 短路求值 | `show(false and missing);` | 输出 `false`，不访问 `missing` |
| 数组读写 | `let a <- [1]; a[0] <- 2; show(a);` | 输出 `[2]` |
| 数组越界 | `show([1][1]);` | RuntimeError，退出码 70 |
| 结构字段 | `shape P { x; } let p <- P { x: 3 }; show(p.x);` | 输出 `3` |
| 缺少字段 | `shape P { x; y; } let p <- P { x: 1 };` | RuntimeError，退出码 70 |
| 分支唯一执行 | `when false { show(1); } otherwise { show(2); }` | 输出 `2` |
| 循环控制 | 0 到 4 循环，2 时 continue，4 时 break | 输出 `0`、`1`、`3` |
| 函数返回 | `craft f(x) { give x + 1; } show(f(4));` | 输出 `5` |
| 默认返回 | `craft f() {} show(f());` | 输出 `null` |
| 词法作用域 | 内层 `let x <- 2` 遮蔽外层 `x <- 1` | 依次输出 `2`、`1` |
| 闭包 | 内层函数读取声明环境中的变量 | 输出捕获的值 |
| 错误位置 | 使用未定义变量 | stderr 包含文件、行、列、`RuntimeError` |

## 3. 歧义消除示例

### 3.1 赋值结合性

```whr
let a <- 1;
let b <- 2;
a <- b <- 7;
show(a, b);
```

`<-` 右结合，输出 `7 7`。

### 3.2 对象身份相等

```whr
let a <- [1];
let alias <- a;
let other <- [1];
show(a == alias, a == other);
```

输出 `true false`。

### 3.3 块作用域中的赋值

```whr
let count <- 0;
{
    count <- 1;
    let local <- 2;
}
show(count);
show(local);
```

先输出 `1`，随后第二个 `show` 产生未定义名称 RuntimeError，退出码 70。先前输出保留。
