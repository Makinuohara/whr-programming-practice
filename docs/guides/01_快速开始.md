# WHR 快速开始

这份指南面向第一次接触 WHR 的同学。目标是用几分钟写出一个能检查、能运行、能测试的 `.whr` 程序。

## 1. 前提与入口

WHR 解释器使用 Python 3.11 或更高版本实现，只依赖 Python 标准库，不需要安装第三方包。请在仓库根目录执行命令；源码文件使用 UTF-8 编码并以 `.whr` 结尾。

先确认入口：

```bash
python --version
python -m whr --version
```

解释器的完整语义以[WHR v1.0 语言规范](../language/01_WHR语言规范.md)为准，内建函数见[标准库说明](../language/02_标准库.md)。本指南只挑最常用的部分说明，不重复完整 EBNF。

## 2. 第一个程序

创建 `hello.whr`：

```whr
show("Hello, WHR!");
```

推荐先检查，再运行：

```bash
python -m whr --check hello.whr
python -m whr hello.whr
```

`--check` 只做词法和语法检查，不执行 `show`；成功时没有输出。运行模式应该输出：

```text
Hello, WHR!
```

仓库已经提供一个同样用途的[最小示例](../../examples/hello.whr)。

## 3. 值、变量和输出

WHR 的基本运行时类型是整数、字符串、布尔值和 `null`。变量用 `<-` 初始化：

```whr
let name <- "Alice";
let score <- 95;
let passed <- score >= 60;
show(name, score, passed, null);
```

赋值是表达式，且右结合：

```whr
let a <- 0;
let b <- 0;
a <- b <- 7;
show(a, b); # 7 7
```

`show` 的参数用一个空格分隔并在末尾换行；直接传入的字符串不带引号。WHR 没有浮点数，也不会把整数或字符串自动转换成布尔值。

## 4. 数组

数组可以为空、混合类型和嵌套，下标从 0 开始：

```whr
let scores <- [92, 88, 96];
show(scores[0], len(scores));
scores[1] <- 90;
push(scores, 100);
show(scores, pop(scores));
```

数组是可变对象。把数组赋给另一个变量得到同一个数组的引用，因此通过别名修改会互相可见：

```whr
let original <- [1];
let alias <- original;
push(alias, 2);
show(original); # [1, 2]
```

负下标和越界下标都会产生运行时错误，不表示“从末尾取值”。

## 5. 结构类型与 `form`

先用 `shape` 声明字段，再用明确的 `form` 构造实例：

```whr
shape Student {
    name;
    score;
}

let student <- form Student {
    name: "Alice",
    score: 95
};
student.score <- student.score + 1;
show(student.name, student.score, student);
```

`form` 是 WHR 的结构构造关键字。不要写成 `Student { ... }`：普通标识符后面的花括号要留给控制流块。构造时字段必须完整、不能重复、不能出现未知字段；字段输出顺序遵循 `shape` 声明顺序。结构声明至少要有一个字段。

## 6. 分支和循环

条件必须是布尔值；`when 1 { ... }` 不会被当作“真”，而是运行时错误。

```whr
let score <- 78;
when score >= 90 {
    show("excellent");
} otherwise when score >= 60 {
    show("pass");
} otherwise {
    show("retry");
}

let i <- 0;
repeat while i < 3 {
    show(i);
    i <- i + 1;
}
```

`break` 离开最近一层循环，`continue` 直接进入最近一层循环的下一轮条件判断。循环条件也必须是布尔值。

## 7. 函数、返回和闭包

函数用 `craft` 声明，用 `give` 返回：

```whr
craft add(left, right) {
    give left + right;
}

craft make_adder(base) {
    craft add_base(value) {
        give base + value;
    }
    give add_base;
}

let add_five <- make_adder(5);
show(add(2, 3), add_five(7)); # 5 12
```

函数参数数量必须完全匹配。函数执行到末尾或执行 `give;` 时返回 `null`。嵌套函数按声明位置捕获变量，这就是词法闭包。数组和结构作为参数传递对象引用，在函数中修改会被调用者看到。

## 8. 输入输出与标准库

`read()` 读取一行，EOF 返回 `null`；`read("提示")` 会先输出不换行的提示：

```whr
let name <- read("name: ");
when name == null {
    show("no input");
} otherwise {
    show("hello", name);
}
```

当前标准库只有课程需要的确定性函数：`show`、`read`、`len`、`push`、`pop`、`to_int`、`to_string`、`type_of`。WHR v1.0 不提供文件、网络、随机数或时间函数；需要完整签名和错误条件时阅读[标准库文档](../language/02_标准库.md)。

## 9. 常用开发循环

每次修改后按以下顺序操作：

```bash
python -m whr --check path/to/program.whr
python -m whr path/to/program.whr
python -m tests.run_all --filter relevant_category
```

完成一项功能后，再运行全量黑盒测试：

```bash
python -m tests.run_all
python -m unittest discover -s tests -p 'test_*.py'
```

第一步常见错误是把 `shape` 构造写成旧草案的 `Student { ... }`，或把 `1`、`null` 当成布尔条件。遇到错误时先保留最小复现程序，再对照[调试与错误指南](03_调试与错误指南.md)检查类别、行列和退出码。
