# 阶段 6 报告：面向人类与编程 Agent 的 WHR 指南

日期：2026-09-26

阶段状态：完成

## 1. 阶段目标

让第一次接触 WHR 的学生可以快速上手、定位错误并解释设计；让编程 Agent 在不依赖解释器作者口头补充的情况下，能够正确编写和验证 `.whr` 程序。

## 2. 人类文档交付

- `docs/guides/01_快速开始.md`：从 hello 到主要语言能力和开发循环；
- `docs/guides/02_开发指南.md`：程序组织、数据建模、函数/闭包、控制流惯用模式和需求拆解；
- `docs/guides/03_调试与错误指南.md`：按错误阶段、类别、退出码和最小复现定位；
- `docs/guides/04_Agent任务模板.md`：可复制的需求、约束、验证和停止规则。

这些指南链接冻结规范而不复制完整 EBNF，重点说明“为什么这样设计、怎样正确使用、怎样证明程序正确”。

## 3. 项目级 Agent Skill

Skill 位于 `.agents/skills/whr-language/`：

- `SKILL.md`：触发边界、非显然约束和必需工作流；
- `references/quick_reference.md`：写程序时按需读取的语法/语义速查；
- `references/verification.md`：单文件、黑盒、全量验证和失败分诊。

按照 `skill-creator` 原则，入口没有重复整本手册，也没有无用途的 README、脚本或 UI 元数据。结构构造 `form`、严格布尔、无隐式转换、确定性标准库和实际验证是会改变 Agent 决策的核心约束。

## 4. Skill 结构验证

当前基础 Python 环境没有 PyYAML，直接执行官方验证器会缺依赖；使用一次性 `uv` 环境验证：

```text
uv run --with pyyaml python \
  /Users/makinuohara/.codex/skills/.system/skill-creator/scripts/quick_validate.py \
  .agents/skills/whr-language
Skill is valid!
```

同时检查了 7 个新增 Markdown 文件中的全部本地相对链接，目标均存在。

## 5. 示例验证

`examples/guide_demo.whr` 覆盖基本值、数组、结构、函数、闭包、分支、循环、输入和输出。

```text

level: excellent

```

`--check` 和执行均返回 0。

## 6. 独立前向测试

一个未参与解释器或指南编写的新 Luna Max 只得到 Skill 路径和成绩报告需求，在 `/tmp` 隔离目录生成 66 行 WHR 程序。固定输入输出、EOF、相关黑盒和全量测试全部通过。

主智能体保留了：

- 独立源码：`examples/agent_skill_validation.whr`；
- 完整任务与结果：`docs/agent_logs/06_skill_forward_test.md`。

这个测试比检查关键词更有说服力：它证明新 Agent 会主动使用 `form`、`to_int`、布尔 EOF 判断和项目验证命令。
